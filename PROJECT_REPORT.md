# VBCUA Project Report Outline

## 1. Title
Voice-Based Concept Understanding Analyser (VBCUA)

## 2. Problem statement
Traditional oral evaluation is time-consuming and subjective. VBCUA provides automated feedback on conceptual understanding and communication quality from spoken explanations.

## 3. Objectives
- Convert spoken explanations to text.
- Measure semantic alignment with a reference concept.
- Detect filler words.
- Estimate pauses, energy and speaking rate.
- Produce an interpretable score.
- Generate PDF reports.
- Maintain evaluation history.

## 4. Modules
1. Presentation Layer
2. Speech-to-Text
3. Semantic Understanding
4. Filler Analysis
5. Audio Feature Extraction
6. Evaluation Scoring
7. Report Generation
8. Database Repository
9. REST API
